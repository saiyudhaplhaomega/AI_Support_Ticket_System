# About NOAVIA

NOAVIA provides a workspace for handling support requests and keeping customer-service information organised.

The public support experience is designed to help visitors submit a clear request, receive guidance based on approved information, and reach a person when a question needs review.

NOAVIA does not use its public assistant as a replacement for a human decision. When approved information does not answer a question, the assistant should say so instead of guessing.

For account-specific help, include a short description of the issue and the email address associated with the workspace when contacting support. Do not send passwords, reset links, API keys, or other secrets in a message.
